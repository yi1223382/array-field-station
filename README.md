# 阵列场站

这是一个无需安装依赖的天线学习与行业情报看板。它既可以在本机打开，也可以通过局域网共享，或发布成任何电脑都能访问的公网网站。

## 使用

- 双击桌面的“阵列场站”快捷方式。
- 首页默认展示最新一期。
- 使用“历史期刊”查看往期内容。
- “打印 / 保存PDF”可生成便于标注的学习档案。

## 让其他电脑访问

### 同一 Wi-Fi / 局域网（立即可用）

1. 双击 `启动局域网访问.cmd`。
2. 窗口会显示一个或多个“其他电脑”地址，例如 `http://192.168.1.8:8080/`。
3. 让其他电脑连接同一个 Wi-Fi，在浏览器输入该地址。
4. 保持启动窗口开启；关闭窗口后共享停止。

如果 Windows 防火墙首次询问，只需允许“专用网络”访问。这个方式不需要复制网页文件，但只能在同一网络内使用。

### 任何地点、任何电脑（公网网址）

项目已包含 GitHub Pages 自动发布配置 `.github/workflows/deploy-pages.yml`：

1. 在 GitHub 新建一个仓库，并把本目录提交到仓库的 `main` 分支。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment → Source** 中选择 **GitHub Actions**。
4. 推送完成后，打开仓库的 **Actions** 页面等待部署成功。
5. GitHub 会生成 `https://你的用户名.github.io/仓库名/`，其他电脑无需安装任何东西，直接用浏览器访问。

以后修改 `content.js` 并推送到 `main`，公网页面会自动更新。请注意：发布到公开仓库后，简报内容和网页资源也会公开。

## 内容更新

Codex每日自动化会在北京时间早上8点研究公开信息，并更新 `content.js`。
新一期应插入 `window.DAILY_BRIEFS` 数组首位，保留旧内容。

## 文件

- `index.html`：页面结构
- `styles.css`：视觉样式
- `app.js`：交互与渲染
- `content.js`：每日简报数据
